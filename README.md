# Stream-Deck
Esse é um projeto feito com base e orientação no vídeo " Stream Deck DIY: Projeto Completo do Zero 🛠️" (https://youtu.be/X_ZKeOIq-ek?si=5c7IvWdgUty-dgnx) do canal no youtube JuliaLabs (https://www.youtube.com/@Julia_Labs).
Para esse projeto foram adquiridos os componentes:
Raspberry Pi Pico Rp2040 (https://www.mercadolivre.com.br/raspberry-pi-pico-rp2040-eletronica-programacao-maker-python/p/MLB34010962?pdp_filters=item_id:MLB5141673961&sid=purchases)
10 Un Switch Marrom Teclado Mecânico (https://www.mercadolivre.com.br/10-un-switch-marrom-teclado-mecanico/p/MLB2106881843?pdp_filters=item_id%3AMLB7297985118&sid=purchases)
Além disso também foi usado uma impressão 3D na Creality Ender 5 para fazer a case, com modelo ajustado para Rapberry Pi Pico (https://makerworld.com/pt/models/496646-9-key-mechanical-macropad#profileId-2344067)
